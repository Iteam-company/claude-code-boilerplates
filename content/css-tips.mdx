# 5 CSS Tricks I Use Every Day

## 1. Centering with flexbox

The classic — works every time:

```css
.container {
  display: flex;
  align-items: center;
  justify-content: center;
}
```

## 2. Clamp for fluid typography

No more breakpoints just for font sizes:

```css
h1 {
  font-size: clamp(1.5rem, 5vw, 3rem);
}
```

## 3. Gap instead of margins

Use `gap` on a flex or grid container instead of adding margins to children — much cleaner.

## 4. :not() to exclude elements

```css
li:not(:last-child) {
  border-bottom: 1px solid #eee;
}
```

## 5. aspect-ratio

```css
.thumbnail {
  aspect-ratio: 16 / 9;
  object-fit: cover;
}
```

Simple, and replaces the old padding-top hack entirely.

# How I Built This Blog with Next.js and MDX

I wanted a blog where I could write in Markdown but still drop in React components when needed. MDX turned out to be the perfect fit.

## The stack

- **Next.js** (App Router) — routing and static generation
- **MDX** — posts as `.mdx` files in a `content/` folder
- **Tailwind CSS** — styling, including the `prose` typography plugin

## How posts work

Each post is an MDX file that exports its own metadata:

```ts
export const metadata = {
  title: 'My Post',
  date: '2026-05-02',
};
```

The `[slug]/page.tsx` route dynamically imports the right file based on the URL, and `generateStaticParams` pre-renders them all at build time.

## What I like about this setup

No database, no CMS, no API calls. Just files. It deploys instantly to Vercel and writing a new post is as simple as creating a new `.mdx` file.

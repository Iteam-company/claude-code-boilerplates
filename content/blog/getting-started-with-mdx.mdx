MDX lets you use JSX in your Markdown content. You can import components, use expressions, and build rich interactive documents without leaving your writing flow.

## What is MDX?

MDX is a format that lets you write JSX inside Markdown files. Think of it as Markdown that can do more — you get all the familiar syntax for headings, lists, and code blocks, plus the full power of React components.

```mdx
# Hello World

This is a paragraph with **bold** text.
```

## Why Use MDX?

There are a few compelling reasons to adopt MDX in your project:

- **Expressiveness** — write documentation and blog posts that include live examples
- **Reusability** — import the same React components you already have
- **Familiarity** — the syntax is just Markdown with optional JSX sprinkled in

## Frontmatter

With `@next/mdx`, you export your post metadata directly as a JavaScript object at the top of the file. This keeps metadata and content co-located while staying valid MDX syntax.

```mdx
export const frontmatter = {
  title: 'My Post',
  date: '2025-05-01',
  tags: ['mdx', 'nextjs'],
};
```

## Code Blocks

You can include fenced code blocks with syntax highlighting:

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet('World'));
```

## Getting Started

Install the required packages, configure `next.config.ts`, and create your first `.mdx` file in the `content/blog/` directory. That's all it takes to publish your first post.
